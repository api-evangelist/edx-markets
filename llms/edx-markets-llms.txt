# EDX Markets

> EDX Markets is an institutional cryptocurrency exchange operating the world's only centrally cleared crypto trading venue. It runs a spot exchange (EDX Markets), a perpetual-futures exchange (EDXM International, Singapore), a clearinghouse (EDXM Global), and a crypto-as-a-service platform (EDX FlowConnect). Connectivity is FIX 5.0 SP2 over mTLS — there is no public REST/OpenAPI surface. This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's published venue resources.
